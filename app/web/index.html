                  长条物件计算方式

                  客户端和计分版本会一起影响长条怎么判，常见的四种组合是：

                  • stable + V1：旧版 stable 的 ScoreV1。长条整条算一个判定，头和尾的误差合并；晚松在 OK 窗口内仍可能给 100。
                  • stable + V2：stable 开 ScoreV2。长条的头和尾分开判，尾判窗口放大 1.5 倍；和 lazer 的 V2 很接近。
                  • lazer + V1：lazer 里查看旧 V1 成绩的兼容口径。长条仍按合并误差算，主要用于对照老成绩。
                  • lazer + V2：lazer 的默认口径。长条头尾分开判，尾判在松手时结算，体中断开会按 MEH 封顶。

                  设置里的“Lazer 方式”对应 lazer + V2，也适合 stable + V2；“Stable 方式”对应 stable + V1，也适合 lazer 的旧 V1 成绩。

                  怎么用

                  1. 在 osu! 里打开成绩详情 → 导出回放，得到一个 .osr，拖到这里。
                  2. 谱面会按回放里的 MD5 自动从曲库匹配；匹配不到会让你手动选 .osu。
                  3. 「总览」看总体评价与失误成因；「时间轴」看波动；「失误清单」逐条看原因；「回放」边听边看。

                  失误是怎么分类的

                  • 超出能力范围：失误集中在高密度、高难度 pattern，且同类片段里反复吃亏。
                  • 节奏感弱：误差方向稳定地偏（一直偏早/偏晚），换密度也照样偏。
                  • 分神：失误成簇突发、伴随长停顿、难度不高、之后立刻恢复。

                  判定窗口按 mania 的 OD 公式计算（MAX ±16ms，300/200/100/50 随 OD 收窄）。UR = 误差总体标准差 × 10。
