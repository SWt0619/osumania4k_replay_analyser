                参考内容

                判定口径、难度与段位都建立在这些项目/服务上

                • ppy/osu 判定窗口口径、测试回放与 ScoreV1 计分公式的依据
                • Etterna MinaCalc：MSD 难度分与七维雷达图
                • sayobot 谱面镜像站。本地没有音频时从这里补一份，取不到再试 nerinyan、catboy；只在缺音频且开关打开时联网
                • osumania_map_analyser 段位估算的实现来源。Roxy 与 Azusa 两套算法、RC / LN 段位标尺都原样取自这里（见 app\web\vendor\mma）； Roxy 是 4K RC 的元结构估算器，用 Ridge 元模型融合 Azusa / Daniel 的预测， Azusa 则融合 Daniel 与 Sunny 的结果。算法细节见 Roxy / Azusa 文档
                • Sunny Rework Sunny 星级与长条（LN）星级。Roxy / Azusa 只做 4K RC，长条占比高的谱面在这里只用 Sunny 估段位
                • Daniel Daniel 难度算法，作为 Azusa 与 Roxy 的输入之一

                  长条物件计算方式

                  客户端和计分版本会一起影响长条怎么判，常见的四种组合是：

                  • stable + V1：旧版 stable 的 ScoreV1。长条整条算一个判定，头和尾的误差合并；晚松在 OK 窗口内仍可能给 100。
                  • stable + V2：stable 开 ScoreV2。长条的头和尾分开判，尾判窗口放大 1.5 倍；和 lazer 的 V2 很接近。
                  • lazer + V1：lazer 里查看旧 V1 成绩的兼容口径。长条仍按合并误差算，主要用于对照老成绩。
                  • lazer + V2：lazer 的默认口径。长条头尾分开判，尾判在松手时结算，体中断开会按 MEH 封顶。

                  设置里的“Lazer 方式”对应 lazer + V2，也适合 stable + V2；“Stable 方式”对应 stable + V1，也适合 lazer 的旧 V1 成绩。

                  怎么用

                  第 1 / 7 页

                  三种导入方式，挑顺手的用。文件只在本机读，不会上传到任何服务器。

                  1. 直接拖：把 .osr 拖到窗口任意位置；也可以点顶栏右上角的导入按钮选文件。
                  2. 从 osu! 导出：选好图进游戏打完，在结算屏按 F2，游戏会提示回放已保存。
                  3. 快捷导入：程序开着的时候，结算屏先按 F2，再按 Shift+F2（可在设置里改），页面会自己接住刚导出的那一份，不用再选文件。

                  谱面是怎么配上的

                  • 回放里记着谱面的 MD5，程序拿它去曲库里找同款 .osu，找到就直接算。
                  • 找不到（超长图、刚下的图、曲库路径没设对）会弹窗让你手动选 .osu，并告诉你缺的是哪一张。
                  • 只在 lazer 玩过的图可能存在 lazer 的 files 目录里，把 lazer 路径填进设置就会一起索引。

                  只看谱面

                  把 .osu 拖进来，不读成绩，只算难度和键型构成，适合赛前挑图。

                  入口被浏览器挡住时，还有一条不过浏览器的路：把 .osr 复制到页面给出的 _replays 目录，直接点文件名。

                  一局打完先看这一页：结果怎么样、主要问题在哪。

                  • 等级与总评：等级按这张图的难度和你的准确率给；总评一句话点出最该改的地方。
                  • 四个数字：准确率（跟着顶栏口径走）、UR（误差离散程度，越小越稳）、击打偏差（每次击打偏离目标的典型幅度，不分早晚）、最大连击。
                  • 判定分布：320 / 300 / 200 / 100 / 50 / miss 各多少个，和回放头记录的数字一致。
                  • 亮点与短板：按分段、键型、判定类型挑出来的，不是套话。
                  • 相似谱面：从曲库里找难度接近、键型相近的图，拿来补同类。

                  顶栏的 V1 / V2 是什么

                  长条判定的两套口径：V1 头尾合并算一次，V2 头尾分开算（尾判窗口是 1.5 倍）。切换之后准确率、判定分布、报告措辞会一起重算，不用重新导入。选和自己客户端一致的那个。

                  整局偏移和击打偏差别混

                  整局偏移带正负号，看的是有没有系统性偏早/偏晚；击打偏差只看幅度。有早有晚时前者会互相抵消成 0，后者仍然很大——两个都对，问的不是同一件事。

                  想知道「从哪一刻开始崩的」，看这两页。

                  时间轴

                  • 最上面的密度曲线是每秒音符数（NPS），峰值段就是最吃体力的地方。
                  • 准确率与 UR 随时间各一条线，掉下去的位置往往就是断连的起点。
                  • 在曲线上点一下或按住拖动，会直接跳到那一刻；进度条上也有播放竖线跟着走。

                  失误清单

                  • 每条失误都带成因（能力 / 节奏 / 分神 / 失手）和可信度；可信度低的是「证据不足」，不是「判定错了」。
                  • 筛选：只看某一类、只看严重；默认一次渲染 30 条，用「再看 100 条」「全部展开」加量。
                  • 点一条会跳到回放页，并停在音符落下前 0.2 秒——不自动播放，方便看清那一击。
                  • 「隐藏低可信度」的门槛在设置里调（0~1，默认 0.5）。

                  边听边看，判断是手慢、听错，还是根本读不出来。

                  • 播放：按空格或点按钮播放/暂停（在回放页和时间轴页都有效），进度条可拖，倍速 0.5× ~ 1.5×。
                  • 下落：音符从画布顶端落到判定线花多少毫秒，越小越快；300 ~ 2600ms 可调。
                  • 音画：画面整体提前/延后，±500ms，用来对齐你自己设备的延迟。
                  • 打击音：选「正解音」听到的是谱面要求的时间，选「实际击打」听到的是你真正按下的时间。两个交替听，抢拍和拖拍会立刻暴露。打击音量最高 300%，回放音量仍然最多 100%。
                  • 只看失误：只画失误附近的音符，密集段落也能看清是哪一轨出的问题。
                  • 对比：导入同一张图的第二份回放，两路并排、吃同一条时间轴，可以直接比同一段谁的手更稳。

                  帧率上限在设置里（30 ~ 240 帧或「无限制」），想确认实际跑到多少，勾上性能面板看右下角。

                  判断这张图是什么类型、难在哪一段。

                  • MSD：MinaCalc 给的综合难度和六维雷达（速度、耐力、技术、叠、乱等），只看谱面本身。
                  • 段位估计：依次用 Sunny → Azusa → Roxy 估，卡片上标了实际生效的是哪一个；低段位图 Roxy 不给值，会自动回退到 Azusa。
                  • 键型构成：切、叠、乱、耐力、速度各占多少，用来解释为什么失误集中在某一段。
                  • 判定分布：这张图上你的 320 占比，比准确率更直观地反映稳定性。
                  • LN 松手偏差：长条是早松还是晚松，左侧蓝、右侧粉，右侧列是具体毫秒。

                  已知限制：谱面的 BPM 如果是歌曲实际 BPM 的整数倍，切 / 叠判定可能错乱；遇到明显不对的构成，先怀疑这一点。

                  只想找几张图练、又没有具体目标时用它：选好段位和键型，程序会给你这个段位上下各一段的图。

                  • 类型：常规和面条二选一。常规按 RC 段位（1 段到 Alpha 以上）；面条按 LN 段位（LN 5 到 LN 17），只给长条占一半以上的图。两者不能同时选，因为面图的 RC 段位和 LN 段位差得远，混着筛一定挑歪。
                  • 段位：选一个段位，程序取它的 ±1 段。比如选 Reform 6 就是 5~7 段，选 LN 7 就是 LN 6~8。
                  • 键型：切 / 叠 / 乱 / 技 / 面，单选。面条模式下这一项会变灰——面图的主键型本来就是长条，再选没有意义。
                  • 自动刷新：改任何一项都会立刻重新抽一批，不用再点按钮；「再找一次」是同一条件下换一批没出现过的图。±1 段里凑不够 8 张时会自动放宽，并在下方注明放宽到了多少。
                  • 点封面下载：左上角是段位、右上角是星数，底部一行是时长、段位名称、键型占比（面条模式显示长条占比），封面本身就是下载链接（sayobot 镜像）。

                  图库是随程序发布的 4 万张 2020 年后 4K 图，筛选完全离线；封面走 osu! 官方 CDN，断网时只显示底色，不影响下载。

                  把每局存下来，估算离下一段还有多远。

                  1. 第一次进成长页先填自己的 osu! 名字——不联网，只用来区分导入的是不是本人的回放。
                  2. 选一个当前段位基准：REFORM 或 Malody；Malody 的段位会按段位谱实测表换算成 REFORM。
                  3. 之后每导入一局都会自动记档，不用手动保存。
                  • 综合段位：取最好的 50 局；上方是目标进度条，右侧写着还差多少段。
                  • 四类练法：叠 / 技术 / 速度 / 耐力各取最好的 10 局，能看出偏科在哪。
                  • 明细：点综合卡片展开 5×10 共 50 格，每格有歌名、难度名、准确率和折算段位；点练法卡片展开该类实际计入的 10 局。
                  • 鼠标停在格子上会说明它为什么没进分键型评估（例如「键型分散，最高 Jack 32%」）。

                  折合规则：V1 准确率 96% 为过段线，91% 以下不计入；LN 与 Hybrid 谱面不参与；键型分散的图只进综合、不进分键型。这套评估是程序自己拟合的，仅供参考。

                  设置里值得看一眼的

                  • osu! 目录：stable 选到有 osu!.exe 的那一级；lazer 选到同时有 Songs 和 files 的那一级。保存后会重扫曲库。
                  • 快捷导入：默认 Shift+F2，可以改，但至少要带一个修饰键。
                  • 回放帧率上限：30 / 60 / 90 / 120 / 180 / 240 帧或「无限制」，默认 120。选得太高会给 CPU 更多压力，性能跟不上时程序会自动降低一档。
                  • 性能面板：勾上后右下角显示渲染帧率、屏幕刷新率、每帧绘制耗时，排查卡顿时用。
                  • 禁用动画：勾上后切换页面不再播放过渡动画，界面直接到位；默认关着。
                  • 长条计算方式：Lazer（默认）和 Stable 的尾判算法不同，选和自己客户端一致的。

                  常见问题

                  • 准确率和游戏里差一点点？判定口径（V1/V2）、客户端版本、尾判细节都会造成 0.0x% 的差别，靠近就是对的。
                  • 提示曲库里没有这张谱面？先确认设置里的目录填对；还是找不到，就在弹窗里直接选 .osu。
                  • 拖进去没反应 / 浏览器上传被挡？把 .osr 复制到页面给出的 _replays 目录，点文件名——这条路不过浏览器，服务端自己读盘。
                  • 点下面的「测试后端连接」没反应？说明本地服务没起来，重开一次启动器。
